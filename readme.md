# Genetic Syndrome Embedding Classification

This project implements a complete machine learning pipeline for classifying genetic syndromes using precomputed 320-dimensional image embeddings.

The objective is to:

- Analyze embedding space structure
- Visualize data distribution
- Perform classification using K-Nearest Neighbors (KNN)
- Compare Cosine and Euclidean distance metrics
- Evaluate performance using F1-score, AUC, and Top-k Accuracy
- Generate reproducible tables and figures
- Produce comparative ROC curves

This project was developed as a standalone Python implementation (no Jupyter notebooks), fully compliant with the provided requirements.

## How to Run the Full Pipeline
The entire workflow—from data ingestion to final metric calculation—is orchestrated by a single script.

To run the pipeline, simply execute:
```bash
python main.py
```
To show the available arguments, run:
```bash
python main.py -h
```

## Execution Flow
1. **Data Processing**: Loads the pickle file, flattens the `syndrome_id` -> `subject_id` -> `image_id` hierarchy, and cleans the data.
2. **EDA**: Generates statistics and plots the distribution of images per syndrome.
3. **Visualization**: Reduces the 320-dimensional embeddings to 2D using t-SNE and saves a colored scatter plot.
4. **Classification**: Evaluates the KNN algorithm using both Cosine and Euclidean distance metrics, determining the optimal $k$ (from 1 to 15) via 10-fold cross-validation (StratifiedGroupKFold is used to prevent subject-level data leakage).
5. **Metrics & Evaluation**: Calculates Top-$k$ Accuracy, Macro F1-Score, and Multi-class AUC. It then generates the summary tables and the comparative ROC AUC curves.

## Outputs
All deliverables generated by the code will be automatically saved to the `output_dir` directory (default: `reports/`).
* `reports/figures/`: Contains `syndrome_distribution.png`, `tsne_visualization.png`, `metrics_vs_k_*.png`, and the final `comparative_roc_curve.png`.

* `reports/tables/`: Contains `metrics_summary_cosine.csv` and `metrics_summary_euclidean.csv` detailing the exact performance numbers for both algorithms.
